# 实验室 SOP｜公开色卡上传（一页）

**目的**：每周稳定上架可检索色卡；图规范、编号唯一、不踩红线。  
**署名**：uploader 填 `DF-LAB`。

---

## 1. 怎么拍

- **同一套条件**：固定灯箱或固定工位光；不要混自然光/射灯乱切。  
- **背景**：中性灰或实验室统一底板；勿花布、勿杂物入镜。  
- **构图**：样板居中，边缘留白；一张主图即可（P0）。  
- **对焦**：纹理清晰；避免过曝、偏色滤镜、美颜。  
- **勿拍**：配方瓶、克数标签、调色单入镜。

拍完当日导出，文件名先用临时名，入库前按编号重命名。

---

## 2. 命名与编号

- **编号 `code`**：`F-` + 五位数字，如 `F-00031`。全库唯一，只增不改号。  
- **色名 `name`**：对外能念、能写进方案的名字（如「黄柚木」）；避免内部黑话。  
- **图片文件**：建议 `{code}.jpg`（或 png）；与 JSON 的 `image` 对应。  
- **勿用**：客户姓名、订单号当公开色名。

与打板工作台将来共用同一 `code`；公开库先发出去的号，现场样板尽量贴同号。

---

## 3. 必填字段

| 字段 | 规则 |
|------|------|
| `code` | 唯一；格式 `F-xxxxx` |
| `name` | 2～12 字为宜；不空 |
| `color` | 有效 hex（示意色，可从规范图取色） |
| `finish` | 必填，如「哑光开放」「半哑封闭」 |
| `image` | 必有规范图 |
| `tags` | 建议 ≥1：树种 / 色系 / 冷暖 / 场景等 |
| `uploader` | `DF-LAB` |

入库前自检：缺图、缺编号、缺 finish → 不上架。

---

## 4. 何时不上架

- 图模糊、严重偏色、条件与库内主流不一致  
- 仅有口头色名、无实物样板  
- 涉及配方、克数、未授权客户专色且不便公开  
- 与已有条目重复（同实物同工艺）→ 合并或停更，不双挂  
- 不确定能否对外署名 DF-LAB 的样品  

不上架的进「待定」夹，写一句原因，下周再审。

---

## 5. 每周节奏（建议）

| 节点 | 动作 |
|------|------|
| 周一～三 | 选样 / 打样 / 规范拍摄（目标本周净增 ≥5） |
| 周四 | 取色填 hex、写 name/finish/tags、编新 `code` |
| 周五 | 写入库（或交 Cursor/表格）；抽查检索与详情页 |
| 月末 | 清点总数；冲刺保底公开 ≥30（P0） |

一人负责编号本（表格或飞书），避免两人同发一个号。

---

## 6. 红线（贴工位）

- 不公开配方、克数、调色比例  
- 不写「对色 90%」「屏色可验收」  
- 图与文不一致不上架
