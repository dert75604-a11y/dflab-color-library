# PRD｜DF-LAB 公开数字色卡库 P0

**产品**：免费公开的木作/涂装数字色卡库（行业参考）  
**对外标题/署名**：上海·DF-LAB 色彩数据库（短版：DF-LAB · 色彩数据库）  
**仓库**：`dflab-color-library`  
**版本**：P0｜2026-10-23  
**边界**：只做公开层露出；不公开配方；不承诺屏色=实物。

---

## 1. 一句话

实验室打出的实物样板，做成可检索的数字色卡；设计师与客户先来选色、对编号；要落地再联系打样。

---

## 2. 用户故事

| 角色 | 想要 | 以便 |
|------|------|------|
| 设计师 | 快速搜到接近的色名/编号与规范图 | 方案阶段有统一颜色语言可写进图纸 |
| 业主/客户 | 在手机上浏览色卡并转发单条链接 | 和设计师、门店对齐「说的是哪一块」 |
| 门店/工厂 | 按标签浏览、记下 code | 对客沟通时引用同一编号 |
| 实验室运营 | 按规范上传、每周补量 | 库持续增长且署名始终是 DF-LAB |

## 5. 数据字段（兼容现有 JSON）

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `code` | ✓ | 如 `F-00001`，全库唯一 |
| `name` | ✓ | 对外色名，如「黄柚木」 |
| `color` | ✓ | hex，如 `#8b7355`（示意色，非验收依据） |
| `finish` | ✓ | 如「哑光开放」 |
| `image` | ✓ | 规范图（P0 可 data URL；P1 建议对象存储） |
| `tags` | 建议 | 树种/色系/场景等，数组 |
| `uploader` | ✓ | 固定或默认 `DF-LAB` |

---

## 6. 与「打样」的关系

- 本站 = **参考与对编号**，不是验收工具。  
- 详情页/页脚提供「需要实物色 → 联系打样」入口（文案克制）。  
- 不在本站承诺对色百分比、交期、报价表（报价另渠）。  
- 后期与打板配色工作台共用 `code`；P0 只预留编号体系，不堵上线。

---

## 7. 验收用例（8 条）

1. 陌生人打开首页，**3 秒内**能说出：这是色彩数据库、谁做的（上海·DF-LAB）。  
2. 顶栏或首页可按名称或编号检索；结果列表可点进详情。  
3. 公开色卡条目 **≥ 30**，每条有规范图、code、name、finish。  
4. 详情页可见 hex 与 tags（有则显示）；uploader 为 DF-LAB。  
5. 页脚或首页常驻免责：**屏显色 ≠ 实物色，落地以打样为准**。  
6. 全站**无**配方克数、无「对色 90%」类承诺。  
7. 单条色卡可生成可转发链接（分享路径可用）。  
8. 移动端可完成：浏览网格 → 开详情 → 看免责（无横向撑破）。
